Автотесты для Stellar Burgers

Автоматизированные тесты на Selenium для проверки регистрации, входа, навигации, выхода и работы раздела «Конструктор».

Структура проекта

- 'locators.py' – локаторы элементов страницы.
- 'utils.py' – функции генерации email и пароля.
- 'conftest.py' – дополнительные фикстуры (опционально).
- 'stellar_burgers_tests' – тесты, разделённые по функциональности.
- '.gitignore' - файл для игнорирования файлов и директорий.

Запуск тестов

bash
python -m unittest discover -s tests

Необходимо, чтобы был установлен ChromeDriver и Python библиотеки:

bash
pip install selenium
