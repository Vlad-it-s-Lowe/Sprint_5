Fвтоматизациz UI-тестов для сервиса Stellar Burgers
https://stellarburgers.nomoreparties.site/

Структура проекта:
файл README  служит руководством к данному проекту;
в папке tests лежат файлы с тестами, для каждой функциональности — свой файл;
в файле helpers лежат функции, генерирующие рандомные данные для тестов регистрации;
в файле conftest лежат фикстуры, необходимые для запуска тестов;
файл locators определяет и описывает локаторы, используемые в тестах;
в файле data хранятся тестовые данные полей ввода;

В рамках тестирования нужно проверить исполнение конкретных функциональных требований:
тесты в файле test_registrarion проверяют позитивные и негативные сценарии при заполнении полей формы регистрации;
тесты в файле test_authentication покрывают четыре сценария аутентификации в приложении;
тесты в файле test_navigate_to_constructor покрывают два сцерания перехода в конструктор бургера из личного кабинета пользователя;
тест в файле test_navigate_to_personal_account проверяет функциональность перехода в личный кабинет с главной страницы;
тесты в файле test_switch_blocks_on_constructor исследуют переключение разделов в меню конструктора;
тест в файле test_logout проверяет функциональность выхода из аккаунта.
